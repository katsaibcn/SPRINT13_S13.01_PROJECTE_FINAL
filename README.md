# The Shuffle Paradox: 
A Personal Reflection on Music Consumption (1983 - 2026)  


## Summary  
This project ingests, cleans, and enriches data from a local music library and Spotify streaming history to examine how discovery, curation, and shuffle habits shifted from owned media to on-demand streaming. Beyond the descriptive analysis, the cleaned dataset and insights inspires a personal experimental tool built around the listening patterns uncovered.

## Introduction  
Music has been an important part of my daily life practically since I can remember. Given the technological transitions I have adopted over the years, I wanted to test whether the contrast between finite, owned physical media ('before') and infinite, on-demand catalogs ('after') has measurably altered my listening choices, discovery patterns, and reliance on shuffle. 

## Analysis question:  
“Have technological advances in music access over the last 15 years - shifting from physical media and local files to on-demand streaming - transformed listening habits?”
